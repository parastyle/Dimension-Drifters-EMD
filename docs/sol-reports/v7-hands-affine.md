## Work log

### Baseline diagnosis

- No nested `AGENTS.md` applies. The in-app browser integration was unavailable (`agent.browsers.list()` returned no browsers), so live work uses the repository's own Playwright/`runArenaSpec` isolation path.
- The shipped V3G mechanism code does not own an accepted-shot clock. `recordAcceptedRangedBeat` arms the generic flourish channel for `epoch + 70 ms`; `tryStartArmedFlourish` is then gated by `quietForEarnedFlourish`. Because `strongerFlourishOwner` includes `rangedAimBlend > 0`, pump/lever work cannot begin while the ranged firing pose is visibly aimed. Held cadence repeatedly cancels/re-arms it, and movement cancels an armed flourish. This exactly explains the invisible-in-play and late-after-release behavior.
- The final two-hand constraint is the correct integration seam: it runs after `weaponMuzzleGripOffset` has mounted the canonical primary firing hand, resolves the secondary point from normalized weapon-art anchors, and never changes the held weapon transform or muzzle affine.

### Implementation

- Replaced the mechanism use of generic `flourishArms` with a retained per-hand `GunHandlingCycleState`. Every advanced authoritative/predicted `attackSeq` starts the tagged mechanism at the accepted presentation epoch, records the accepted sequence and weapon identity, and replaces any prior cycle. It does not wait for aim settle, fire release, idle eligibility, or movement quietness.
- The final secondary-grip constraint samples that accepted cycle only after `weaponMuzzleGripOffset` mounts the canonical firing hand. Pump and lever offsets remain weapon-art-space values passed through `resolveSecondaryGripPosition`; the held weapon, primary hand, recoil affine, muzzle point, server cadence, projectiles, and damage are unchanged.
- Authored explicit smooth phases: pump reaches a rear extremum at 42% then travels forward to home; lever reaches a down extremum at 40% then travels up to home. Default durations are 240 ms pump / 220 ms lever, cadence-capped with a 24 ms home margin so even the 140 ms Sidewinder Twin-Rifles cadence gets a complete per-shot cycle.
- Retuned only existing pump secondary anchors, using the painted PNGs as proof: Rustwidow `0.64,0.78`; Buckshot Briar `0.67,0.76`; Frostbore `0.72,0.79`; Galvanic Coachgun `0.69,0.68`; Hallowbore `0.66,0.58`; Boomstick `0.67,0.49`. Primary anchors and all lever anchors remain unchanged. Regenerated only `weapons-expansion.generated.ts` through its canonical source generator.
- The first after trace exposed two measurement/integration details. Local accepted prediction advances the rig sequence one rendered frame (maximum observed 52.8 ms) before the mirrored authoritative player row; grouping by the latter mixed the next mechanism into the preceding return. The permanent gate now measures the `rigAttackSeq` cycle, requires the identical sequence to appear in authoritative `attackSeq`, and measures onset against both clocks. Separately, `rebuildRenderStack` correctly placed a mechanism hand above the gun, then its generic front-hand tail pushed the gun a second time above that support hand. The duplicate two-hand weapon push was removed; the live gate now checks actual display-list order and bounds intersection at every extremum.
