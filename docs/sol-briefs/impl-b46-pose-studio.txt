## Features (v1)
1. **Stage**: character picker (WHOLE_ART_CHARACTERS) x weapon picker (active catalog, searchable);
   real rig render, BOTH facings side by side; zoom; combat-scale toggle.
2. **Playback**: timeline scrubber over the weapon's combo beats; play/pause/loop; 0.1x-2x speed;
   onion-skin ghost of the previous beat; beat boundaries + timing windows drawn on the timeline.
3. **Drag-drop editing**: on-canvas handles for grip points (primary/secondary), idle-hand pose
   anchors, and per-beat path targets (arc endpoints/reach). Dragging writes the corresponding
   authoring fields live; render updates immediately.
4. **Tweak panel**: per-beat numeric/slider editing of timing (activeStart/End/impact/followEnd),
   path kind/arc/range/damage multipliers, motion name, ribbon profile; pose-language idle
   selection; weapon displayLength/gripFrac. Schema-validated inputs — reject what the model
   cannot express with a clear message (never silently approximate).
5. **Save/Load round-trip**: save to the JSON row, regen, and a "reload game" hint; dirty-state
   indicator; snapshot/restore (single-level undo of the row on disk).
6. STANDING LAWS enforced in-editor: no character displacement fields for melee (hide/lock them),
   gun recoil field visible read-only (B45 owns it), no chain/aura authoring affordances.
