time, not a staler server copy.

- The server stores it per player and uses it for INCOMING resolution.

  robustness against a broken/desynced client, NOT anti-cheat. Say what you clamp to and why.

hitting**. The reverse case — the player sees a hit the server does not — is the ACCEPTABLE direction
and must not be "fixed" by making the server more aggressive.
